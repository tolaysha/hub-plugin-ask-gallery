# ask-gallery — «Только вопросы»

Режим у сессии: на весь экран — только её открытые вопросы (карточки «Сессия ждёт вашего ответа»), по одному, а рядом
с каждым — что было перед ним. Вход — кнопка «Только вопросы» в шапке открытой сессии: она видна, только пока у сессии
есть открытые вопросы (красный «?» и красная обводка — как у строки сессии, которая ждёт вас; число — в подписи).
Вопросы в ленте сессии плагин не сворачивает. Выход — ×, Esc, «Назад» браузера или сам, когда вопросы кончились.

- ←/→ (кнопки внизу, клавиши, свайп на телефоне), счётчик «2 из 5». Листание — как в галерее фото: карточка с
  контекстом целиком уезжает за край, следующая одновременно въезжает с другой стороны (420 мс, плавная остановка);
  частые нажатия и зажатая клавиша не копят анимации.
- Слева от карточки — блок контекста: ближайший к карточке текст сессии из хода, в котором задан вопрос, — её последнее
  сообщение прямо перед карточкой (после предыдущего инструмента или карточки), а если такого нет — последний текст
  этого хода после карточки (итог хода; пока ход идёт, дорисовывается). Более ранние куски хода и другие ходы в блок не
  попадают. Если ход начат вашим ответом на прошлый вопрос этой сессии, над текстом — тот вопрос и ваш ответ (часто ваше
  уточнение своим текстом); ответ, данный ходами раньше, относится к другому вопросу и не показывается. Нечего
  показать — карточка одна, по центру. Текст — штатным рендером ленты; длинный прокручивается внутри блока. На узком
  экране блок над карточкой, свёрнут до нескольких строк, «ещё» раскрывает.
- Ответ — штатной карточкой хаба (варианты, свой текст, мультивыбор, «Нужно больше контекста»): тот же `/api/answer`,
  что у обычной карточки, с повтором и квитанцией. Отвеченная карточка сразу, не дожидаясь квитанции, улетает вверх
  вместе с контекстом — в том виде, в каком вы ответили (без строки «Ваш ответ: … — отправляю»), — а на её место справа
  въезжает следующая (слева — если отвеченная была последней в списке); новые вопросы встают в конец. Хаб не принял
  ответ — карточка возвращается на экран с причиной (а если вы в это время печатаете в другой — причина в шапке,
  карточка ждёт в списке). × на карточке — закрыть вопрос без ответа (как в ленте); Esc — только выйти из режима.
- Вопросы кончились — режим закрывается, как по Esc, как только улетела последняя карточка: без отдельного экрана и без ожидания, пока сессия возьмёт
  ответ. Держит его только замороженная карточка с вашим текстом (её вопрос закрыли в другом месте, пока вы печатали или
  диктовали) — до «Убрать».
- Вопрос закрыли с другого устройства, пока вы печатали свой ответ, — карточка остаётся с вашим текстом, «Убрать».
- Ширину блока контекста и карточки меняют, как у списка сессий: тянут полосу между ними (контекст и карточка делят
  ширину) или правый край карточки (пара шире или уже, остаётся по центру); на полосе ←/→ — шаг (Shift — крупнее),
  двойной клик — ширина по умолчанию. Ширина запоминается и встаёт при каждом открытии режима; окно уже — пара ужимается
  в нём, не ниже читаемого минимума, а запомненное возвращается, когда окно снова шире (потянули в узком окне — это
  новая ширина). На узком экране ручек нет.
- `prefers-reduced-motion`: без сдвигов, листание — простая смена, ответ — плавное исчезновение.
- Данных сессий не хранит; на время вкладки помнит открытую сессию (sessionStorage), чтобы режим пережил перезагрузку, а
  в браузере — выбранные ширины (localStorage `ask-gallery.widths`). Ленту для контекста только читает (`/api/history`,
  как «Показать раньше»).

## Установка

По ссылке: вставьте `https://github.com/tolaysha/hub-plugin-ask-gallery` в поле в «Настройки → Плагины» (или
`hub market review tolaysha/hub-plugin-ask-gallery`) — плагин ставится после проверки кода, ровно проверенный коммит.

Или своим расширением: клон в любую папку и запись в `hub.json` → `extensions` (вписывает владелец или хаб):

```json
"ask-gallery": { "path": "<папка клона>", "web": "web/main.js" }
```

Процесса нет; перезапуск хаба не нужен — страница подхватывает плагин сама.

## Совместимость

`"hub": "^1.32"` — нужен хаб с Plugin API 1.32 и новее (в пределах 1.x; тесты проходят на выпусках ядра 1.7.0–1.8.0).

Плагин импортирует внутренние модули страницы напрямую — это вне Plugin API: `/static/js/cards.js` (`askCard`),
`feed.js` (`item`, `keyOf`), `state.js` (`S`, `sessionLabel`), `dom.js` (`avatarNode`), `recorder.js` (`V`),
`dictate.js` (`dictationIn`), `api.js` (`banner`). В Plugin API нет «нарисуй штатную карточку вопроса» и «нарисуй строку ленты», а плагин
хочет ответ ровно как в ленте (варианты, свой текст, голос, повтор и квитанция). Обновление хаба, переименовавшее или
изменившее эти функции, может сломать плагин даже при том же номере Plugin API — тогда нужна новая версия плагина;
ошибка будет видна в «Настройки → Плагины». Ручки ширины берут вид у разделителя страницы (класс `.grip`, курсор
`body.resizing`) — переименование этих классов оставит ручки рабочими, но без линии при наведении. Правило блока
контекста — в `web/chain.js` (без DOM: его можно прогнать по журналу и вне страницы).

## Проверка

Тесты гоняются из рабочей копии `agents-hub-core` (оттуда берутся `tests/` и `core/`; нужны Python 3.12, `node` и Chrome):

```sh
cd <agents-hub-core>
PYTHONDONTWRITEBYTECODE=1 python3.12 -m unittest discover -s <ask-gallery>/tests -t <ask-gallery>/tests
```

Скриншоты — в папку `HUB_TEST_ASK_SHOTS`, если она задана.
